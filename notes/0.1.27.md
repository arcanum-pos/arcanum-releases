## What's new
### Security
- Changes (saving, payments, the installer) are only accepted from the
  installation's own address — not from other sites on the same domain.
- The services behind Arcanum no longer receive sign-in tokens or cookies
  they don't need.
- Signing in no longer asks the backend for the login provider's client
  secret at all (that route is removed).
- The old session cookie name is no longer accepted. A browser not used
  since 0.1.21 signs in once more.
- A failed sign-in no longer shows technical details.

## Updating
- Nothing to do: the installer updates itself first, then Arcanum. No
  database changes.
