## Fixed
- **Mail: a line with only a dot no longer cuts a mail short.** Text after such a line was lost, and a line starting with a dot lost that dot (".NET" arrived as "NET"). Mails now arrive as written.
- **Mail: a sender name with a comma** (such as "Scouts, Elewijt") is no longer read as two addresses.
- **Names with accents** (such as "Jérôme") from the sign-in are no longer garbled.
- **Text on your own colours:** on some mid-tone branding colours the screens chose the text that reads worse. It now picks the one that reads best.
- **Odd input is refused cleanly.** An unusual pairing link, a mail provider name or an empty request to the device service now gets a plain "not valid" answer instead of an error or a wrong result.
- **The installer:** log lines with special characters no longer break in the middle of a character, a damaged log can no longer make it loop, and starting twice at the same moment can no longer overwrite its key.

## Under the hood
- SMTP passwords are never written to the logs, not even at debug level.
- Random codes (table QR codes, pairing codes, event links) now give every character exactly the same chance.
- Every Arcanum repository is now checked automatically on each change: tests, type check, a scan of the packages for known weaknesses and a code scan. All public repositories also get CodeQL and an OpenSSF Scorecard.
- Releases and images carry signed build provenance, so you can check that they were built from the published sources: `gh attestation verify <file> -R arcanum-pos/arcanum-releases`. The proof is also attached to each release (provenance.intoto.jsonl).
- Build steps and base images are pinned to exact versions (kept current automatically).
- Package and test tooling updates, and many more automatic tests.
- A security policy in every repository: report a vulnerability privately, through the repository's Security tab.
