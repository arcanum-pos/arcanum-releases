## Fixes
- **Notifications when the order is ready now really get offered.** An installation updated to 0.1.59 could end up with a notification key the backend can't use, and then the order page silently didn't offer notifications. This update replaces such a key by itself; nobody can be subscribed with it yet, so nothing is lost.
- **The permission question comes straight from the tap.** The order page now asks for permission the moment the guest taps "Melding aanzetten". Safari can refuse a question that comes later, without showing it.
- **The installer waits for itself.** When an update brings a new installer, the steps after it now wait until that new installer answers, instead of sometimes being run by the old one for a few seconds.

## Good to know
- Notifications don't work in a private (incognito) browser window: the browser refuses them without asking. Guests should open the order page in a normal window.
- On a Mac, Safari only asks when Safari → Settings → Websites → Notifications → "Allow websites to ask for permission to send notifications" is on.

## Updating
- Update as usual: the installer updates itself first, then the rest. No database changes.
