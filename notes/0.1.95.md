## Fixed
- **Installer: no more "Installer unavailable" during an update.** When steps finished quickly one after another, saving the progress could fail: Cloudflare accepts only one save per second. The step itself had worked, but the update stopped and had to be started again. The installer now waits a moment and saves again.
- **Installer: a short interruption no longer stops the update.** If the installer cannot be reached for a moment during an update, the page now tries the same step again by itself, for up to 2 minutes, instead of stopping. A step that fails with its own error still stops and shows that error.

## Updating
- Update as usual. The update does not change the database.
- The installer updates itself first. During this update you may still see "Installer unavailable" once: then start the update again. From the next update on, this no longer happens.
