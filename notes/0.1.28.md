## What's new
### Security
- Every screen (console, kassa, customer display, settings, the QR sign-in
  page) now tells the browser exactly what it may load: scripts only from
  the installation itself, never inside another site's frame. Should a bug
  ever let someone inject code into a page, the browser won't run it.

## Updating
- Nothing to do: the installer updates itself first, then Arcanum. No
  database changes.
