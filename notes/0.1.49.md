## What's new
- **Pair station screens and customer displays without signing in.** On
  the device, open `<your address>/pair` and enter the pairing code, or scan
  the QR code from the console, which now points there.
  - The device gets its own key. Nobody needs to be signed in on it, and it
    keeps working until you remove it under Toestellen; removing it stops it
    straight away.
  - That key only reaches what the device itself needs: a station screen its
    own station's orders, a customer display its own kassa's payments.
  - The sign-in screen now has a link "Toestel koppelen" for this.
  - A kassa still needs someone signed in, so you know who operated it. Its
    code at `/pair` asks you to sign in first.
  - Screens paired before keep working as they are. Pair them again if you
    want them off a personal login.
  - In the demo without an account, you can now add station screens and
    customer displays too.
- **Installer, Aanmelding: the client fields changed places.**
  - The first client is now the one for signing in in the browser. It also
    does the sign-in with the QR code on a kassa, as login.kaboutersoft.be
    does.
  - A separate client for the QR sign-in is optional, for providers that
    need one (Google).
  - Existing settings are moved over by the installer itself; nobody has to
    sign in again.
  - The separate QR client is folded away. It opens by itself for Google, or
    when one is already set.
  - A new link, "Hoe vul ik dit in?", explains the fields and what to set up
    at Google, Keycloak, Microsoft and Auth0.

- **Installer, Beheerders:** a new admin now gets the backend's access
  straight away, so "Installatie" shows in their console after a reload.
  Before, that only happened at the next update, although the admin could
  already open the installer. The text there now also says what admins can
  do: open the installer, and create or import organisations.

## Updating
- Update as usual: the installer updates itself first, then Arcanum. This
  release adds to the database (applied by the installer).
- Reload the station screens and customer displays after updating, or pair
  them again with `/pair` if you want them off a personal login.
