## What's new
- **E-mail belongs to the installation now.** Set it up once in the
  installer, under **Geavanceerd → E-mail**: choose a service, fill in its
  settings and send yourself a test mail. Every organisation on the
  installation sends its invitations through it, with the organisation's
  name as the sender's name.
- **More ways to send mail:** next to SMTP (e.g. iCloud+) and the Gmail API
  (Google Workspace), there are now **Brevo**, **Resend** and **Cloudflare
  Email Service**. For the Gmail API, you upload the service account file
  you downloaded from Google; its private key is never shown again.
- **Cloudflare Email Service** sends through your own Cloudflare account.
  It needs Workers Paid and a domain onboarded for sending in the
  Cloudflare dashboard (Compute → Email Service → Email Sending). The
  installer only offers it when it finds such a domain. To look, your
  installer's token needs two extra read permissions; the installer says
  which ones and how to add them.
- **No mail? Pass the invitation on yourself.** When an invitation mail
  couldn't be sent (no mail set up, or it failed), the console shows the
  invitation text with a **Kopiëren** button, so you can send it by
  WhatsApp or text message. A member who hasn't signed in yet has
  **Uitnodiging kopiëren** in their row menu, for later.
- The console's **Meldingen** page is gone: its per-organisation mail
  settings are replaced by the installation's mail. Exports no longer
  contain mail settings; older export files still import.
- The login provider no longer has an **Auth0 connection** field. It was
  only needed for Auth0 enterprise sign-in and didn't work with signing in
  by phone.

## Updating
- Update as usual: the installer updates itself first, then Arcanum. No
  database changes.
- **Then set up mail** in Geavanceerd → E-mail. It takes effect right away,
  without another update. Mail settings from the console's Meldingen page,
  or set by hand on the Worker, are no longer used. Until you set it up,
  Arcanum sends no invitation mails, but you can copy invitations from the
  console.
