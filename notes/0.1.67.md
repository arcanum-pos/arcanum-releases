## What's new
- **Order page: a clearer message when notifications are blocked.** When a guest's browser blocks notifications (in its settings, or in a private window), the order page now says so right away instead of showing a button that can't work. It explains why, reassures the guest that the page keeps following the order while it's open, and only suggests a text message when the event offers one.

## For self-hosted installations
- Development builds now come with their images too, so installations on Kubernetes or Docker that follow development builds can update. A new version only appears in the installer once its images are ready.

## Updating
- Update as usual: the installer updates itself first, then the rest. No database changes.
