## What's new
- **Ordering modes.** An event can now have several ways orders come in,
  named as you like, for example **Ter plaatse**, **Take away** or **Alleen
  aan de kassa**. Set them up in Evenementen → Instellen. Each ordering
  mode has its own menu, and you choose where it's used: with the QR code
  (guests order themselves), at the kassa, or both. How guests pay and
  ordering on a tab are now set per ordering mode as well.
  - One QR code and one series of order numbers stay per event. With more
    than one mode on the QR, guests first choose how they order. Each mode
    also gets its own direct link that skips this choice, for example for a
    poster at the take-away window.
  - With more than one mode, station screens show it on every order (for
    example **Take away**), as do the kassa and the guest's order page.
    It's information only: which station makes what is still set per
    product. For take away made elsewhere, use separate products.
  - At the kassa: when the event has more than one mode for the kassa, the
    kassa shows a choice for new orders, which stays until you change it.
    The kassa keeps its own menu for now.
- **Keep your order's link.** The guest's order page now offers to share
  its link (to send it to themselves) or copy it. Without that, a private
  window or a closed tab loses the order page.

## Updating
- Update as usual: the installer updates itself first, then Arcanum. This
  release adds to the database (applied by the installer). Events that
  already had self-ordering set up get one mode, "Ter plaatse", with their
  current settings, so nothing changes until you add more.
- Reload the kassas, station screens and customer displays after updating.
