## What's new
- **Pickup screen (Afhaalscherm) for guests.** A big screen per station
  showing the order numbers in three columns: **Ontvangen**, **In
  bereiding** and **Klaar**, with the ordering mode ("Take away") when an
  event has more than one.
  - A number that just became ready lights up for a few seconds. Ready
    numbers leave the screen once marked delivered, or after 15 minutes.
  - Optional sound: tap the speaker icon to hear a chime when a number
    turns ready. The screen remembers it, but browsers ask for one tap
    again after the page is reloaded.
  - Read-only: no names, no order contents, no buttons to change anything.
  - Two ways to open it:
    - **As its own device:** in the console, Toestellen → Toestel
      toevoegen → **Afhaalscherm**, choose the station, and pair the
      device at `/pair` with the code — like a station screen.
    - **From the station screen:** the new **Afhaalscherm** button opens it
      for the same station in a second window (on a second monitor, if the
      browser can tell), like the kassa's Klantscherm. No extra pairing.
  - It updates live, the same way the station screen does.

## Updating
- Update as usual: the installer updates itself first, then the rest. This
  release adds to the database (applied by the installer).
