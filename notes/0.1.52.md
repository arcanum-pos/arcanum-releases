## What's new
- **Several installations on one Cloudflare account.** Each one has its own
  Workers, databases and KV, all starting with the installation's name —
  for example `tresjr-bff` and `tresjr-backend`, or a random name like
  `wildferret-bff` when that one is taken.
  - Useful for a test installation next to the real one, or for several
    clubs, each with its own data.
  - An existing installation keeps its names (`arcanum-…`). Nothing of it
    is renamed or moved.
  - A new installation is made in the bootstrapper (Eigen installatie): on
    an account that already has one, it asks whether to open that one again
    or add a new one next to it. At most 4 fit on Cloudflare's free plan.
- **Signing in without a password.** The login screens now say "with a code
  by e-mail, Google or a passkey". login.kaboutersoft.be no longer uses
  passwords: you get a code (and a link) by e-mail.

## Updating
- Update as usual: the installer updates itself first, then the rest. No
  database changes in this release.
