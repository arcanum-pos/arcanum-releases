## What's new
### SumUp readers
- **Pair a reader from the console.** Under Toestellen, "Reader koppelen":
  enter the code the SumUp Solo shows (pairing via API, in its connection
  settings) and a name. A paired reader can be unpaired there too.
- **Testing without real money:** create a sandbox account in your SumUp
  account (Developer Settings → Sandboxes), enter its merchant code and API
  key in a test organisation, and pair SumUp's **Virtual Solo**
  (virtual-solo.sumup.com) with the code it shows. Payments then go
  through SumUp for real, without money changing hands.

### Removed
- **The SumUp simulator** is gone: the Virtual Solo replaces it. A device
  that was set up as a simulator asks again what it is the next time it's
  opened. Old simulator registrations are marked "vervallen" under
  Toestellen and can be removed there.
- A SumUp payment without a reader works as before: the cashier confirms
  it on the kassa.

## Updating
- Nothing to do: the installer updates itself first, then Arcanum. No
  database changes.
