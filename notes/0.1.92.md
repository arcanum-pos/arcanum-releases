## New
- **Easy start for a new organisation.** When you create an organisation in the console, "Start met een voorbeeldmenu" is now ticked by default. The organisation then starts with the example menukaart from the demo, in the language of the person who creates it. Untick it to start empty.
- **"Aan de slag" on the Overzicht.** Until an organisation has a menukaart and a kassa, the Overzicht shows an "Aan de slag" card with the steps:
  - **Menukaart:** add the example menukaart with one click, or enter your own products. The example is only offered in an organisation that has no products or menukaarten yet, so it can never end up on top of your own menu.
  - **Kassa:** "Gebruik deze browser als kassa" opens the kassa in a new tab, like the demo does. Or choose "Koppel een iPad of tablet" and pair a device as usual.
  - **Kassalade:** optional.
  
  You can hide the card. It is hidden per organisation, on that browser.

## Changed
- **Kasbeweging: shorter labels.** The buttons now say "Erin" and "Eruit" so the text fits. The examples are still shown in the reason field.
- **Safer sign-in cookies.** The session cookies are now checked more strictly. You will not notice anything.
- Several components were brought up to date (small version updates, no changes in behaviour).

## Updating
