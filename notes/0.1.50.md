## What's new
- **Bancontact: you see which account a key pays out to before it's kept.**
  - On save, Arcanum starts a test payment of €0.01 with the key and cancels
    it straight away. Nothing is paid. The console then shows the account
    the money would go to: its name and the last digits of its IBAN.
  - Only after **Ja, bewaren** is the key kept. If it isn't your account,
    don't save it.
  - Every payment is checked against that account. If Bancontact ever
    answers with a different one, the payment is cancelled and refused.
  - The card under Betaalproviders shows the account. A key saved before
    this release says "not checked": set it again to see and confirm it.
- **SumUp: the merchant code and key are checked together.**
  - On save, Arcanum asks SumUp whether the key works for that merchant
    code, and shows the account's name to confirm. A key that doesn't
    belong to the code is refused.
  - The card shows the account and merchant code. Keys saved before stay in
    use and show "not checked" until you set them again.
- **Station screen:** switching the filter while an order came in could
  briefly show the old filter's tickets. Fixed.

## Updating
- Update as usual: the installer updates itself first, then Arcanum. No
  database changes in this release.
- Recommended afterwards: under Betaalproviders, set the Bancontact and
  SumUp keys again once, so their account is checked and shown.
