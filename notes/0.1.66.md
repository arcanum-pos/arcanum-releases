## What's new
- **Self-hosting with Docker or Podman (preview).** Next to Cloudflare and Kubernetes, Arcanum can now run on a single machine of your own with Docker or Podman. A compose file from arcanum.kaboutersoft.be starts only the installer; it creates the rest itself — one container per part on its own network, the data in volumes, the database brought up to date before a new version starts — and updates it all, itself included, with one click. You route your own https address to it (a reverse proxy or a Cloudflare Tunnel).

## For installations on Cloudflare and Kubernetes
- Nothing changes.

## Updating
- Update as usual: the installer updates itself first, then the rest. No database changes.
