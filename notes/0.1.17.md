## What's new

### A quieter install screen
The individual install steps are folded away under **Details van de
installatie**. While installing or updating, one line under the button shows
which step it's on. Open the details to see every step.

## Updating
- Nothing to do: the installer updates itself first, then Arcanum. No
  database changes.
- Only the installer changed in this release; the other components are the
  same as in 0.1.16.
