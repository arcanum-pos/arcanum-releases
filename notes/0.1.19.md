## What's new
- **Open je Arcanum** now always switches the installer's own address off
  first when it's still on, then opens the console. It checks at the moment
  you click. A login change that was already applied no longer keeps the
  address on (undoing it works through Arcanum).
- The install summary is a short list: address, Cloudflare account,
  administrators.

## Updating
- Nothing to do: the installer updates itself first, then Arcanum. No
  database changes. Only the installer changed.
