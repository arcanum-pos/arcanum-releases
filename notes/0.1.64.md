## What's new
- **Self-hosting on Kubernetes (preview).** Arcanum can now also run in your own Kubernetes cluster instead of on Cloudflare — installed and updated by the same installer, with one-click updates. A Helm chart puts the installer in your cluster; it does the rest: every part as its own Deployment, its data in SQLite on a volume, the database brought up to date before a new version starts (with a copy of it first). You route your own https address to it (Ingress, Gateway or a Cloudflare Tunnel). This release is the first with the images (`ghcr.io/arcanum-pos/tresjr-…`) and the chart (`oci://ghcr.io/arcanum-pos/charts/tresjr-installer`).

## For installations on Cloudflare
- Nothing changes in how Arcanum works. Under the hood every part can now also run outside Cloudflare; the mailer and the screens' server were tidied up for that, and a few small things got sturdier on the way (the mailer closes its SMTP connection when the sign-in is refused).

## Updating
- Update as usual: the installer updates itself first, then the rest. No database changes.
