## Improved
- **One button to add any device.** Under Toestellen, "Toestel toevoegen" now also covers SumUp card readers: choose **SumUp-kaartlezer** as the type and type in the code the reader shows. The separate "Reader koppelen" button is gone.
- **Delete an event** you no longer need, as long as nothing was sold for it yet (no tabs, no sales). Its ordering modes go with it. An event with sales stays, and the console says why.
