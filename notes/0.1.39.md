## What's new
- **Pairing with the QR code takes one step less.** Scanning a device's QR
  code in the console (Toestellen → Toestel toevoegen) now pairs the device
  straight away and opens it: no "Koppelen" to press any more. Typing the
  code by hand works as before.
- **A real kassa is never replaced by accident.** If a browser that already
  is a kassa or customer display opens a pairing link for another
  organisation, it now asks first: keep what it is, or pair with the new
  code.
- **The demo starts on a kassa.** Trying Arcanum on arcanum.kaboutersoft.be
  now opens your demo on a ready-to-use kassa ("Kassa 1"), since that's
  what most people will use. A bar at the top says when the demo
  disappears and leads to the console for the menu, devices and reports.
  (Only for the demo installation.)

## Updating
- Nothing to do: the installer updates itself first, then Arcanum. No
  database changes.
