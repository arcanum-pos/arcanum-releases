## What's new

### See which installer you're running
The installer's page now shows its own version in the footer
("Installer 0.1.13"). When you update, the installer first updates itself
to the release's installer and then Arcanum — after the update the footer
names the new version, so you can see it did.

## Updating
- **An installer set up with the Deploy to Cloudflare button** (before
  0.1.12) doesn't update itself yet: it runs from its own copy of the code
  in your GitHub account. Update it once by hand — on GitHub, open your
  `arcanum-installer` repository and click **Sync fork**; Cloudflare then
  deploys the new installer (its settings and password are kept). From
  then on it updates itself with every release.
- No database changes.
